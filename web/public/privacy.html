개인정보 처리방침

시행일 2026년 11월 8일 · 마지막 수정 2026년 11월 8일

성공은 성균관대학교 공지와 인턴 공고를 모아 보고, 나에게 맞는 공지를 알림으로 받는 웹 앱입니다. 학생 개인이 만들어 운영하며 학교의 공식 서비스가 아닙니다. 이 글은 성공이 어떤 정보를 어디에 쓰고 어떻게 지우는지 알려 드립니다.

1. 받는 정보와 쓰는 곳

구글 로그인으로 받는 정보이메일 주소, 이름, 프로필 사진 주소. 로그인과 계정 구분, 화면의 계정 표시에 씁니다.
서비스를 쓰면서 저장하는 정보받을 게시판, 관심 키워드, 저장한 공지와 읽음 표시, 프로필(전공, 학년, 학기, 재학 상태, 병역, 직접 적은 관심 분야 글), 알림 기기 정보(브라우저 알림 주소와 키, 기기 이름).
직접 연결했을 때만 저장하는 정보내 Gemini 키, 내 아이캠퍼스 토큰, 구글 캘린더를 연결했을 때 구글이 주는 장기 열쇠(모두 암호화해서 저장), 만들어진 구글 캘린더의 번호, 내 키로 만든 공지 판정·요약·번역·마감 결과.

성공은 광고를 하지 않고, 정보를 팔거나 광고에 쓰지 않습니다.

2. 누구에게 맡기는지

  • Supabase: 로그인과 데이터 저장.
  • Cloudflare: 웹 페이지 제공.
  • Oracle Cloud: 공지를 모으고 알림을 보내는 서버.
  • Google: 구글 로그인. 내가 켠 경우에 한해 Gemini(내 키로 공지 판정·요약·번역)와 Google Calendar(저장한 공지의 마감 넣기).
  • 성균관대학교 아이캠퍼스: 내가 토큰을 넣은 경우에 한해 내 과제·퀴즈·강의 마감을 읽습니다.

공지는 학교와 인턴 공고 사이트의 공개 게시판에서 가져오며 개인정보가 들어 있지 않습니다.

3. Google 사용자 데이터

  • 구글 캘린더: 내가 "구글 캘린더에 연결하기"를 눌러 허용한 경우에만 쓰며, 권한은 성공이 만든 "성대 공지" 캘린더 안의 일정을 만들고 고치고 지우는 것으로 제한됩니다. 내 다른 캘린더는 읽지도 쓰지도 못합니다. 구글이 연결할 때 주는 장기 열쇠(갱신 열쇠)는 암호화해서 서버에 보관하고, 서버가 30분마다 저장한 공지를 이 캘린더에 맞추는 데만 씁니다. 넣는 내용은 저장한 공지의 제목, 원문 링크, 마감 시각입니다. "연결 끊기"를 누르거나 계정을 지우면 이 열쇠도 바로 지워지고, 구글 계정의 연결된 앱에서 권한을 거두면 서버도 더는 쓰지 못합니다.
  • Gemini: 내가 내 키를 넣은 경우에만 공지 제목과 본문, 그리고 내 프로필의 일부 글(전공, 학년, 학기, 재학 상태, 병역, 직접 적은 관심 분야)을 내 키로 Google에 보내 판정·요약·번역·마감 추출 결과를 받습니다. 이름, 학번, 연락처는 받지 않으며 보내지 않습니다.
  • 성공이 Google API로 받은 정보를 쓰는 일은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 따릅니다. 이 정보는 위 기능을 제공하는 데만 쓰고, 광고나 다른 용도로 쓰거나 사람이 읽지 않으며 제3자에게 넘기지 않습니다.

4. 안전하게 보관하는 방법

  • Gemini 키, 아이캠퍼스 토큰, 구글 장기 열쇠는 AES-256-GCM으로 암호화해서 저장하고, 암호문은 브라우저에서 읽을 수 없습니다. 풀어서 쓰는 것은 해당 사용자의 요청을 처리하는 서버 작업뿐입니다.
  • 모든 사용자 정보는 계정별로 나뉘어 있어서 다른 사용자의 정보는 읽거나 고칠 수 없습니다.

5. 얼마나 보관하고 어떻게 지우는지

  • 계정이 있는 동안 보관합니다.
  • 설정 > 계정 > 계정 지우기를 누르면 계정과 위의 모든 정보(구독, 키워드, 저장·읽음, 프로필, 키와 토큰, 알림 기기, 판정·요약 결과)가 바로 지워집니다. 되돌릴 수 없습니다.
  • Gemini 키와 아이캠퍼스 토큰은 설정의 연결 키에서 각각 지울 수 있고, 구글 장기 열쇠는 구글 캘린더 화면의 "연결 끊기"로 지울 수 있고, 알림 기기는 설정의 알림에서 지울 수 있습니다.
  • "구글 캘린더 연결 끊기"를 눌러도 구글 캘린더에 이미 만들어진 "성대 공지" 캘린더와 일정은 남습니다. 필요 없으면 구글 캘린더에서 직접 지워 주세요. 구글 계정의 연결된 앱 관리에서 성공의 권한을 거둘 수도 있습니다.
  • 이 브라우저에 남는 설정과 캐시(읽음 표시, 화면 설정 등)는 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.
